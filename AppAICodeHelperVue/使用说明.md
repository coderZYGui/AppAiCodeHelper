# AI编程小助手 - 使用说明

## 🚀 快速启动

### 方法一：使用启动脚本（推荐）
1. 双击 `start.bat` 文件
2. 等待依赖安装完成
3. 浏览器会自动打开应用

### 方法二：手动启动
1. 打开命令行，进入项目目录
2. 运行 `npm install` 安装依赖
3. 运行 `npm run dev` 启动开发服务器
4. 在浏览器中访问 `http://localhost:3000`

## 📋 使用前准备

### 1. 安装Node.js
- 访问 https://nodejs.org/
- 下载并安装最新的LTS版本
- 确保Node.js版本 >= 16

### 2. 启动后端服务
确保您的SpringBoot后端服务正在运行：
- 后端地址：`http://localhost:8081`
- 接口路径：`/api/ai/chat`

## 💬 使用功能

### 聊天界面
- **发送消息**：在底部输入框输入问题，按Enter键发送
- **换行输入**：按Ctrl+Enter键可以换行
- **实时对话**：AI回复会实时流式显示
- **会话管理**：每次刷新页面会生成新的会话ID和内存ID

### 界面说明
- **用户消息**：显示在右侧，蓝色背景
- **AI回复**：显示在左侧，白色背景
- **正在输入**：AI思考时会显示动画效果
- **会话ID和内存ID**：显示在页面顶部，用于区分不同对话

## 🔧 常见问题

### Q: 页面无法打开？
A: 检查Node.js是否正确安装，确保端口3000未被占用

### Q: 无法连接到后端？
A: 确保SpringBoot后端服务正在运行在8081端口

### Q: 消息发送失败？
A: 检查网络连接和后端服务状态

### Q: 样式显示异常？
A: 尝试清除浏览器缓存或使用现代浏览器

## 🛠️ 开发说明

### 项目结构
```
ai-code-helper/
├── src/
│   ├── App.vue          # 主应用组件
│   ├── main.js          # 应用入口
│   └── style.css        # 全局样式
├── index.html           # HTML模板
├── package.json         # 项目配置
├── vite.config.js       # Vite配置
└── README.md           # 项目说明
```

### 修改配置
- **后端地址**：修改 `src/App.vue` 中的SSE连接地址
- **样式**：修改 `src/style.css` 或 `src/App.vue` 中的样式
- **端口**：修改 `vite.config.js` 中的端口配置

### 构建部署
```bash
# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 📞 技术支持

2. 后端服务是否正常运行
3. 网络连接是否正常
4. 浏览器是否支持SSE
