# 程序员常见面试题

## Java基础面试题

### 1. 面向对象编程
**Q: 解释Java中的封装、继承、多态？**
- **封装**：将数据和操作数据的方法绑定在一起，隐藏内部实现细节
- **继承**：子类可以继承父类的属性和方法，实现代码复用
- **多态**：同一个接口可以有不同的实现，运行时决定调用哪个实现

**Q: 抽象类和接口的区别？**
- 抽象类可以有构造方法，接口不能
- 抽象类可以有非抽象方法，接口中的方法默认都是抽象的（Java 8后可以有默认方法）
- 一个类只能继承一个抽象类，但可以实现多个接口
- 抽象类可以有实例变量，接口中的变量默认是public static final

### 2. 集合框架
**Q: ArrayList和LinkedList的区别？**
- **ArrayList**：基于数组实现，随机访问快O(1)，插入删除慢O(n)
- **LinkedList**：基于双向链表实现，插入删除快O(1)，随机访问慢O(n)

**Q: HashMap的工作原理？**
- 基于哈希表实现，使用数组+链表+红黑树结构
- 通过key的hashCode()计算数组索引
- 当链表长度超过8时转换为红黑树
- JDK 1.8后采用尾插法避免死循环

**Q: ConcurrentHashMap如何实现线程安全？**
- JDK 1.7：分段锁机制，将数据分成多个段，每个段独立加锁
- JDK 1.8：CAS + synchronized，只锁定当前操作的节点

### 3. 多线程
**Q: 创建线程的几种方式？**
1. 继承Thread类
2. 实现Runnable接口
3. 实现Callable接口
4. 使用线程池

**Q: synchronized和Lock的区别？**
- **synchronized**：JVM层面的锁，自动释放，不可中断
- **Lock**：API层面的锁，手动释放，可中断，支持公平锁

**Q: volatile关键字的作用？**
- 保证变量的可见性
- 禁止指令重排序
- 不保证原子性

### 4. JVM相关
**Q: JVM内存结构？**
- **堆内存**：存储对象实例，分为新生代和老年代
- **方法区**：存储类信息、常量、静态变量
- **栈内存**：存储局部变量、方法参数
- **程序计数器**：记录当前执行的字节码指令地址
- **本地方法栈**：为native方法服务

**Q: 垃圾回收算法？**
- **标记-清除**：标记垃圾对象后清除，会产生内存碎片
- **复制算法**：将内存分为两块，复制存活对象到另一块
- **标记-整理**：标记后将存活对象向一端移动
- **分代收集**：根据对象存活时间采用不同算法

## Spring框架面试题

### 1. Spring核心
**Q: Spring的核心特性？**
- **IOC（控制反转）**：对象的创建和依赖关系由Spring容器管理
- **AOP（面向切面编程）**：将横切关注点从业务逻辑中分离
- **声明式事务**：通过注解或配置管理事务
- **集成性**：与各种框架良好集成

**Q: Bean的生命周期？**
1. 实例化Bean
2. 设置属性值
3. 调用BeanNameAware的setBeanName()
4. 调用BeanFactoryAware的setBeanFactory()
5. 调用ApplicationContextAware的setApplicationContext()
6. 调用BeanPostProcessor的预初始化方法
7. 调用InitializingBean的afterPropertiesSet()
8. 调用自定义的init方法
9. 调用BeanPostProcessor的后初始化方法
10. Bean可以使用了
11. 调用DisposableBean的destroy()
12. 调用自定义的destroy方法

### 2. Spring MVC
**Q: Spring MVC的工作流程？**
1. 用户发送请求到DispatcherServlet
2. DispatcherServlet查询HandlerMapping找到处理器
3. 执行处理器（Controller）
4. Controller返回ModelAndView
5. DispatcherServlet查询ViewResolver解析视图
6. 渲染视图并返回给用户

**Q: @RequestMapping和@GetMapping的区别？**
- @RequestMapping：通用的请求映射注解，可以指定请求方法
- @GetMapping：专门处理GET请求的注解，是@RequestMapping的简化版

## 数据库面试题

### 1. MySQL相关
**Q: 索引的类型和作用？**
- **主键索引**：唯一标识表中的每一行
- **唯一索引**：保证列值的唯一性
- **普通索引**：提高查询效率
- **复合索引**：多个列组成的索引
- **全文索引**：用于全文搜索

**Q: 事务的ACID特性？**
- **原子性（Atomicity）**：事务是不可分割的最小单位
- **一致性（Consistency）**：事务执行前后数据保持一致
- **隔离性（Isolation）**：并发事务之间相互隔离
- **持久性（Durability）**：事务提交后永久保存

**Q: MySQL的存储引擎？**
- **InnoDB**：支持事务、外键、行级锁，默认存储引擎
- **MyISAM**：不支持事务，表级锁，查询速度快
- **Memory**：数据存储在内存中，速度快但数据易丢失

### 2. SQL优化
**Q: 如何优化慢查询？**
1. 添加合适的索引
2. 避免SELECT *，只查询需要的字段
3. 使用LIMIT限制结果集大小
4. 避免在WHERE子句中使用函数
5. 使用EXPLAIN分析查询计划

## 算法与数据结构

### 1. 常见算法
**Q: 排序算法的时间复杂度？**
- **冒泡排序**：O(n²)
- **选择排序**：O(n²)
- **插入排序**：O(n²)
- **快速排序**：平均O(nlogn)，最坏O(n²)
- **归并排序**：O(nlogn)
- **堆排序**：O(nlogn)

**Q: 二分查找的实现？**
```java
public int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

### 2. 数据结构
**Q: 链表反转的实现？**
```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

## 系统设计面试题

### 1. 分布式系统
**Q: 如何设计一个高并发系统？**
1. **负载均衡**：使用Nginx或硬件负载均衡器
2. **缓存**：Redis、Memcached缓存热点数据
3. **数据库优化**：读写分离、分库分表
4. **消息队列**：异步处理，削峰填谷
5. **CDN**：静态资源加速
6. **微服务**：服务拆分，独立部署

**Q: CAP定理是什么？**
- **一致性（Consistency）**：所有节点同时看到相同的数据
- **可用性（Availability）**：系统持续可用
- **分区容错性（Partition tolerance）**：系统在网络分区时仍能工作
- 三者不可兼得，只能选择其中两个

### 2. 缓存设计
**Q: 缓存穿透、缓存击穿、缓存雪崩的解决方案？**
- **缓存穿透**：查询不存在的数据，使用布隆过滤器或缓存空值
- **缓存击穿**：热点数据过期，使用互斥锁或永不过期
- **缓存雪崩**：大量缓存同时过期，设置随机过期时间
